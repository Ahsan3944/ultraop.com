# Creator Photos - Asset Synchronization Guide
==================================================

Welcome! Any photo or image placed in this folder ("Creator Photos") is directly synchronized with the website.
When you replace any file here with your personal photo or logo, the website updates automatically without modifying any code.

--------------------------------------------------
SUPPORTED PHOTO FILENAMES & PURPOSES:
--------------------------------------------------

1. CREATOR PHOTO (Your Profile & Biography Photo)
   - Accepted File Names:
     • creator_photo.png
     • creator_photo.jpg
     • creator_photo.jpeg
     • creator_photo.webp
     • creator_photo.svg
   - Used In: "Meet the Creator (Sk Ahsan Ahmad)" Biography section and hero profile cards.

2. OFFICIAL CHANNEL LOGO (YouTube & Brand Emblem)
   - Accepted File Names:
     • channel_logo.png
     • channel_logo.svg
     • channel_logo.jpg
     • channel_logo.jpeg
     • channel_logo.webp
   - Used In: Top Navigation bar, Channel Logo Inspection popup, Footer branding, and Hero badges.

3. GAME PROFILE LOGO / MASCOT (Gamer Avatar & Esports Icon)
   - Accepted File Names:
     • game_profile_logo.png
     • game_profile_logo.svg
     • game_profile_logo.jpg
     • game_profile_logo.jpeg
     • game_profile_logo.webp
   - Used In: In-game profile badge, Streamer verified stamp, and Arcade leaderboard mascot.

4. BATTLE STATION & SETUP PHOTO (Dual-Monitor Studio)
   - Accepted File Names:
     • setup_photo.png
     • setup_photo.jpg
     • setup_photo.jpeg
     • setup_photo.webp
     • setup_photo.svg
   - Used In: "Inspect Battle Station Setup" Studio Tour modal.

--------------------------------------------------
HOW TO UPDATE:
--------------------------------------------------
1. Simply copy or drag-and-drop your photo into this "Creator Photos" folder.
2. Rename it to one of the exact names above (e.g. "creator_photo.jpg" or "channel_logo.png").
3. The website will immediately display your original photo in all corresponding sections!
