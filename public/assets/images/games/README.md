# Interactive Games Hub Assets
==================================================

Directory for browser arcade game covers, UI sprites, sound effects, and badge assets.

## Supported Games:
- `esports-quiz/` — Multi-Game Trivia & Gamer Certificate banners.
- `zen-tile/` — Zen Harmonic 2048 tiles and soothing visual accents.
- `bubble-garden/` — Zen bubble physics and blossom sprites.
- `aim-trainer/` — Reflex Aim Pro target rings and crosshair icons.
- `cyber-strike/` — Galaxy starship and laser particle assets.
- `neon-snake/` — Cyber snake glowing grid themes.
- `cyber-dash/` — Hovercraft obstacle tunnel sprites.
