# Creator Photos & Gallery Architecture
==================================================

This directory contains photography and visual assets of Sk Ahsan Ahmad (UltraOP).

## Structure:
- `hero/` — Full-length or portrait photography for Hero and Home banners (`hero-creator.jpg` / `hero-creator.webp`).
- `profile/` — High-resolution headshot for About section, biographies, and author cards (`creator-profile.jpg`).
- `gallery/` — Live tournament events, studio sessions, fan meetups, and award ceremonies.

## Auto-Synchronization:
Files can be placed either in these dedicated subfolders or directly into `/public/Creator Photos/`. The website's asset resolution pipeline automatically detects and prioritizes uploaded high-resolution photos over fallback illustrations.
