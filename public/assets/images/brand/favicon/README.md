# UltraOP Favicon & App Icon System
==================================================

This folder contains browser favicons, mobile touch icons, and PWA icon assets.

## Files:
- `favicon.svg` — Scalable high-contrast vector favicon for modern browsers.
- `apple-touch-icon.svg` — 180x180 vector icon for iOS home screen bookmarks.
- `favicon.ico` (optional binary multi-resolution bundle).
- `favicon-16x16.png` & `favicon-32x32.png` (optional raster legacy fallbacks).
