# Open Graph (OG) & Social Card Image Architecture
==================================================

This directory contains social preview images (1200x630px, 1.91:1 aspect ratio) for sharing on Discord, Twitter/X, WhatsApp, Facebook, and LinkedIn.

## Standardized File Matrix:
- `og-default.svg` / `og-default.jpg` — Universal social card preview.
- `og-home.jpg` — Dedicated homepage social share banner (Pending custom photograph).
- `og-about.jpg` — Biography & Creator showcase social share image.
- `og-projects.jpg` — Minecraft SMP & Community projects card.
- `og-games.jpg` — Arcade & Esports Trivia mini-games portal banner.
- `og-blog.jpg` — Guides & Sensitivity Lab sharing preview.

## Specifications:
- Resolution: 1200 x 630 px
- Formats: JPG / WebP / SVG
- Max File Size: < 350 KB
