# UltraOP Design System & Visual Tokens
==================================================

## Color Tokens:
- **Primary Electric Orange**: `#FF3E00` (Hero accents, interactive CTAs, live pulses)
- **Secondary Warm Orange**: `#FF6B00` (Gradients and hover states)
- **Light Editorial Canvas**: `#F4F4F1` (High-contrast editorial light background)
- **Dark Midnight Canvas**: `#121212` (Streamer midnight dark background)
- **Dark Surface Container**: `#1C1C1C` / `#222222` (Card and panel backgrounds)
- **High-Contrast Text**: `#121212` (Light mode) / `#F4F4F1` (Dark mode)
- **Muted Subtitles**: `#666666` (Light mode) / `#999999` (Dark mode)

## Typography:
- **Display Headings**: `Syne`, `Space Grotesk`, `Playfair Display`
- **Body & Controls**: `Plus Jakarta Sans`

## Micro-Interactions:
- Buttons scale down `active:scale-95` on tap for tactile mobile responsiveness.
- Focus outlines use `focus-visible:ring-2 focus-visible:ring-[#FF3E00]`.
- Glass panels use `backdrop-blur-md` with subtle border opacity.
